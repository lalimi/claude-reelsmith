## Як перезібрати
Потрібні Node 20+, ffmpeg і Playwright з Chromium (у корені репозиторію: `npm install`, або `reelsmith setup`).

```bash
cd ready/2026-10-26-instagram-reel-olena
(cd source && npm install)        # один раз: бібліотека motion
node source/render.mjs            # ≈ 1.5 хв: reel.mp4 + cover-slide-01.png
node source/render.mjs --stills 1,5,12,20   # лише контрольні кадри в source/stills/
```

- **Озвучка:** поклади запис у `input/voiceover.m4a` (або `.mp3`, `.wav`) і запусти `node source/render.mjs`. Голос вирівнюється до -14 LUFS, відео лишається тим самим.
- **Своє відео (режим A):** поклади `input/lalita.mp4` і запусти `node source/render.mjs`. Відео стає фоном (cover-crop на 1080x1920, затемнення ink .35), звук береться з файлу, музика не додається. Якщо відео не 22 с, швидкість підрівнюється в межах 0.9-1.1, а надлишок обрізається (якщо коротше навіть на 0.9, останній кадр тримається). Тексти не змінюються, текст і стікери рухаються поверх відео. Перший кадр лишається обкладинкою, далі жовта смуга відкриває відео.
- Папку `input/` шукає в теці рілса, потім у теці, звідки запускаєш. В git вона не потрапляє.
- Режим A перевірено на тестовому відео 20.5 с (швидкість стала x0.933, вийшло рівно 22 с, звук з файлу). На справжньому відео подивись кадри після збірки: текст лежить поверх обличчя, тож може знадобитися інший кадр.

## Як зроблено
- Текст рендериться в HTML шрифтами Unbounded 900 (заголовки, uppercase, line-height .98, letter-spacing -1px) і Onest 500/700. Пружини й easing з бібліотеки Motion (`spring`, `easeOut`, `easeIn`), але кожен кадр рахується від часу `window.__seek(t)`, тому рендер детермінований: 660 кадрів, 30 fps.
- Увесь важливий текст між y=285 і y=1635. Число «1 500 грн» в один рядок, з нерозривними пробілами.
- fal.ai: модель `bria/fibo-2/generate` через MCP, 5 зображень по $0.04. Мережа сесії не пускала до fal CDN, тому взято превʼю з відповіді MCP, фон вирізано локально. Подробиці в `assets/fal/prompts.md`.
- Факти тільки з брифу (банк кейсів, квітень 2026): польська та норвезька, уроки, 1 500 грн, тиждень, без ФОП на BlackSea. Ім'я автора, розмір аудиторії, ціна уроку, кількість покупців і формат уроків у рілс не потрапили.
