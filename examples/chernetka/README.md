# Example: «Сценарій вічної чернетки» (The eternal-draft scenario)

A real 61-second reel for a personal Instagram account, built in one session with this repo: Ukrainian voice-over (ElevenLabs), 15 of the author's own clips from a shared iCloud album, 17 segments. The footage is not included — this folder shows the decisions.

- `script.uk.md` — the approved script (structure "the scenario of …", see `skills/reel-script/references/`). An English adaptation and its beat map are in `skills/reel-script/references/examples.md`.
- `reel.json` — the full edit: cover story with the person in front of the masthead, orbit text on "1000 followers", doodle boil on the confessions, headline wall + glass type on the title, black-and-white for "Tanya from accounting", grey → colour burst into the checklist of steps, zoom-through and whip transitions, end card. `"sfx"` is the CapCut sound-effects pass.
- `caption.uk.txt` — the caption that was posted.
